## 用法

这一页是底座。写任何文档先满足六条原则。句子层面的执行细则见[写作与整理规范](/meta/conventions)第 9 节。

两者冲突时，按用户、事实、语气、形式的顺序取舍。

## 六条原则

1. 用户优先。先写结论；难词先解释；删掉读者不需要的信息。
2. 先认文档类型和受众。笔记、规范、分析文各有结构；分析文用技术简报。
3. 语法完整。一句一个主张；主谓齐全；不用“不是 X，而是 Y”的对偶。
4. 术语一致。查[术语与译名表](/meta/glossary)；首次中英并列，之后统一。
5. 译意不译词。引语逐字；转述写“据……”；不逐词硬译。
6. 资料可核验。先查原文；找不到标“未核验”；不编造。

## 语气

- 直接、清楚、可读。不端着，不堆术语。
- 不写翻译腔：长定语、被动堆叠、名词化。
- 原文啰嗦可以压缩。事实、数字、引语不改。
- 语气随文档类型变：笔记简短，规范精确，分析文密集。

## 术语

查找顺序：

1. 查[术语与译名表](/meta/glossary)。
2. 查术语在线或国标。
3. 查 Microsoft 语言门户（中文）。
4. 查已出版的中文技术书和官方文档。
5. 以上都没有，标“本库约定”，并在表里新增一行。

语境优先于词表。表里没有、语境特殊的，先按语境写，再补表。

## 中文细则

### 称呼

- 对读者用“你”，对自己用“我”。
- “我们”第一次出现时说明指谁。
- 全文只用一个称呼，不混用“你”“您”“开发者”。

### 用词

- 术语、缩略语、同一对象全文只用一个说法，不中英混用。
- 行业通用术语先随国标，再随本库表。
- 不随意缩写英文，不自创缩略语。
- 术语首次出现写成“中文（English，缩写）”。
- 行话、成语先过“能不能译”这一关；译不出，换成具体说法。

常用词：

| 用 | 不用 |
|---|---|
| 登录 | 登陆 |
| 单击 | 点击 |
| 图像 | 图象 |
| 计费 | 记费 |
| 阈值 | 阀值 |
| 重写 | 复写 |
| 命令 | 指令 |
| 外形 | 外型 |

### 句段

- 一句一个主张。读完要回头，就拆。
- 同一句逗号不超过 5 个。这是提示，不作硬指标。
- 不用双重否定。
- 能量化就量化：“文件大于 16MB”，不写“文件超限”。
- 段首给结论，一段一件事。

## 不采用

- 印尼语敬语与正式度分级。
- 对读者称“开发者”。
- 句长、逗号数的硬阈值。
- “不是 X，而是 Y”的对偶。
