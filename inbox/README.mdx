# Inbox

这个目录不发布。

## 放什么

- 临时想法
- 看到的一句话
- 没弄懂的问题
- 想读的书或文章

## 怎么放

一个条目一个文件。
文件名：`YYYY-MM-DD-短标题.mdx`。

## 什么时候整理

AI 每周整理一次。

- 有用：移到 `src/content/docs/notes/`。
- 没用：删除。
- 不确定：留着，标日期，问用户。

## 规则

- 不要求完整。
- 不要求排版。
- 先记，后想。

## 整理后

AI 会：

1. 补 frontmatter。
2. 把链接改成根相对路径。
3. 更新对应主题的 `index.mdx`。
